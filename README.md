# Cybersecurity Portfolio

Hi! I'm Reno — an aspiring cybersecurity analyst. I learn by building: home labs, SIEM deployments, and TryHackMe rooms. I'm starting an associate degree in cybersecurity in January 2027, and this repo documents the hands-on projects I'm building in the meantime.

A note on how I document projects: for me, the value isn't the perfect finished screenshot — it's the troubleshooting trail. Every write-up here includes what went wrong and how I fixed it, because that's where the real learning shows.
